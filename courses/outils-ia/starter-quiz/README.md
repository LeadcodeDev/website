# Projet de départ : mini-quiz

Un petit quiz en terminal, en Python (aucune bibliothèque à installer).

```
python quiz.py
```

Sur Mac et Linux, la commande est souvent `python3 quiz.py`.

## Mission de l'atelier 8

Sauvegarder le meilleur score dans un fichier. Au lancement, le quiz affiche
`Meilleur score : X/5`, avec le meilleur score des parties précédentes.

Vérification :

```
python test_mission.py
```

Il doit afficher `OK`. Fais la mission sur une copie propre du projet : le test
tape lui-même les réponses d'origine et suppose que les questions n'ont pas
changé.

## Idées pour les ateliers 5, 6, 7 et 11

- Niveau 0 : se faire expliquer le code, changer une question ou le message de fin.
- Niveau 1 : ajouter un niveau de difficulté, un chronomètre, un fichier de questions.
- Niveau 2 : écrire des tests, séparer l'affichage de la logique, gérer les erreurs.
